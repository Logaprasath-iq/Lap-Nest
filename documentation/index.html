01. Strict Technology Stack

The project is engineered exclusively using semantic HTML5, production compiled Tailwind CSS v3.4 CLI, and Vanilla JavaScript (ES6+). Zero heavy frontend frameworks (no React, Next.js, Vue, or JSX).

  • Markup: Semantic HTML5 with micro-data, meta tags and ARIA labels.
  • Styling: Tailwind CSS compiled via Node CLI (npm run build:css), utilizing CSS custom variables.
  • Animation: GSAP 3.12, ScrollTrigger, and custom CSS 3D matrix transformations.
  • Charts: Chart.js with custom gold-accented area gradients for dashboard metrics.

03. 3D Transformations & Physics Engine

Implemented in assets/js/three-d.js without three.js overhead, using native GPU-accelerated CSS 3D properties:

  • Hero Laptop 3D Stage: .laptop-3d-model uses perspective: 1600px, rotateX, rotateY, and smooth linear interpolation (lerp) tracking cursor coordinates across the hero section.
  • Interactive Card Tilt: Cards with class .tilt-card tilt up to ±12 degrees dynamically with an active radial specular reflection highlight.
  • Micro-Particle Mesh: HTML5 canvas rendering floating gold particles with auto-connective lines and mouse repulsion forces.
  • Accessibility & Touch Safety: Touch screens and users with prefers-reduced-motion automatically have tilt disabled to conserve GPU memory and ensure comfortable viewing.
